What this does
- Dark desktop skin + polished tables + flashing rows.
- CSS-only. Safe.

Install
1) Folder: C:\Users\Steven\Documents\BIGCHEESE_PUBLIC_S1\static\
2) Backup (optional): app.css, t2_desktop_colors.css
3) Copy from this ZIP into 'static', then rename:
   - app_desktop_clone.css  -> app.css
   - t2_desktop_colors_desktop.css -> t2_desktop_colors.css
4) Publish:
   git add -A
   git commit -m "GUI S2 desktop clone skin"
   git push scalingo master
5) Ctrl+F5 refresh /app
