# UI Style Guide (current app look)

- **Base background:** `#0b0f0f` (very dark teal/black)
- **Accent green:** read from Table‑1 highlight (fallback representative: `#1aff97`)
- **Text (normal):** `#e6e6e6`
- **Buttons (primary):**
  - Normal: `#ff8c2a`
  - Hover: `#ffa64d`
  - Pressed: `#ff7a00`
  - Radius: `10–12px`
  - Weight: semi‑bold / bold
- **Borders:** disabled for dialogs; content panels use neon‑green outlines as in dashboard.
- **Fonts:** take the font family/size from the **Table‑1** rows to keep typography consistent across dialogs.

**Rules of thumb**
- Do not style widgets globally; prefer **per‑dialog** style blocks.
- Leave space on the right of spinboxes so +/- are not clipped (use layout margins).
